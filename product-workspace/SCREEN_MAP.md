# Screen map (web app)

## Public

- `/` Landing (marketing blocks, testimonials, pricing preview)
- `/pricing` Pricing (plans from dynamic config)
- `/auth` Sign in / sign up
- `/legal/privacy` Privacy policy
- `/legal/terms` Terms
- `/help` Help center (dynamic content)

## App (authenticated)

- `/app` Home / mode selector
- `/app/classic` Classic mode dashboard
  - Resume list + resume viewer
- `/app/builder` CV Builder
- `/app/pro` CV Pro Studio
- `/app/jobs` Job tracker (planned)
- `/app/settings` Account settings
  - Plan + billing status, invoices, cancel

## Admin (role-protected)

- `/admin` Admin home
- `/admin/users` Users + plan/subscription state
- `/admin/plans` Plans + pricing table editor
- `/admin/content` CMS-like blocks (landing/help/FAQ/banners)
- `/admin/settings` Operational settings + feature flags + quotas
- `/admin/analytics` Metrics dashboard
- `/admin/audit` Audit logs
- `/admin/support` Support tickets / feedback queue (planned)
