# Feature modules

## 1) Authentication & accounts

- **Purpose**: secure access, role separation, account lifecycle.
- **Free**: signup/login, basic profile.
- **Paid**: billing state, invoices, portal.
- **Admin/internal**: user management, impersonation (optional).

## 2) Classic resumes (core utility)

- Upload/paste, version history, download, delete.
- AI processing (improved versions) with clear status and retries.

## 3) CV Builder (structured creation)

- Draft save + preview + publish to classic.
- Templates (later): 2–3 recruiter-friendly layouts.

## 4) CV Pro Studio (premium engine)

- Diagnosis (free preview + paid depth)
- Job match (paid)
- Rewrite section (paid)
- Export packs (paid)

## 5) Job tracker (retention)

- Track jobs, attach CV versions, generate cover letter drafts.
- Re-run diagnosis with deltas.

## 6) Billing & monetization

- Plans, entitlements, quotas, upgrade prompts.
- Webhooks and billing state handling.

## 7) Admin dashboard (operations)

- Manage users, subscriptions, plans.
- Manage dynamic content/settings.
- View analytics and audit logs.

## Feature classification

- **Free**: classic upload + version viewing + download text; limited diagnosis preview.
- **Basic paid (Pro)**: full diagnosis, rewrites, job match, higher limits, export packs.
- **Premium (Plus)**: multiple profiles, LinkedIn pack, interview prep, priority support.
- **Enterprise/admin**: admin dashboard, support tooling, system settings.
